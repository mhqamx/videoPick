## 一、ECS vs 轻量应用服务器（先帮你做减法）

| 维度 | ECS 云服务器 | 轻量应用服务器（SWAS） | 你的场景 |
|------|------------|---------------------|---------|
| 定位 | 企业级，灵活配置 | 中小项目"开箱即用" | ✅ 选轻量 |
| 计费 | CPU/内存/磁盘/带宽**分别**计费 | 套餐打包价 | ✅ 选轻量 |
| 价格 | 2c4g 1M ~95 元/月 | 2c2g 3M ~68 元/月 或新人 99 元/年 | ✅ 选轻量 |
| 控制台 | 复杂 | 简化版，一键应用镜像 | ✅ 选轻量 |
| 公网 IP | 默认无（要绑 EIP） | 自带 | ✅ 选轻量 |
| 上限 | 无限扩展 | 6c16g 10M 封顶 | 够用，超了再迁 ECS |

**结论**：宣传站 + 解析后端这种轻量场景，**直接买轻量应用服务器（SWAS）**。等真的火了再升级 ECS，阿里云提供"轻量 → ECS"无损迁移。

> 别犹豫，这是 owner 意识——3.25 红线是不要为没到的规模过度设计。

## 三、域名怎么搞（10 分钟流程）

### 3.1 选域名（30 秒）

**后缀优先级**：
1. **`.com`** ← 首选，国际通用，SEO 友好，55~88 元/年
2. **`.cn`** ← 国内备案有加成，39 元/年
3. **`.top` / `.xyz`** ← 便宜，但不推荐做品牌站

**起名策略**（拉通顶层设计）：
- **品牌词 + 业务词**：`videopick.app`、`xiazaibao.com`、`pickvideo.cn`
- **避免**：含敏感词（"VPN"、"翻墙"等）、含商标词（"douyin"、"tiktok" 等会被驳回）
- **测可注册性**：阿里云 → 顶部菜单"产品" → "域名" → 输入想要的名字看是否被占

### 3.2 注册步骤（控制台路径）

```
1. 阿里云首页 → 顶部"产品" → "域名注册"
2. 搜索框输入：videopick（不带后缀）
3. 勾选 .com 那一行 → "加入清单" → "去结算"
4. 选"个人模板"或"企业模板"（如果还没建，去"信息模板" → "新建模板"）
   ├─ 持有者：你的真实姓名（或公司名）
   ├─ 证件类型：身份证
   └─ 证件号：填写并上传身份证正反面照片
5. 实名审核：1~3 个工作日（阿里云速度通常 1 天内）
6. 完成支付
```

> ⚠️ **关键闸门**：域名实名认证不过，备案也办不了。第一天就要把信息模板做好。

### 3.3 域名买完之后

| 行动 | 操作位置 |
|------|---------|
| 配 DNS 解析（指向 ECS 公网 IP） | 阿里云控制台 → 域名 → 解析 → 添加记录 |
| 国内 ECS 需备案 | 阿里云控制台 → 备案 → 提交资料 |
| 海外/香港 ECS 不需备案 | — |

DNS 记录配置示例（以 `videopick.app` 为例）：

| 主机记录 | 类型 | 记录值 | 说明 |
|---------|------|--------|------|
| `@` | A | `47.xxx.xxx.xxx`（ECS 公网 IP） | 根域名 |
| `www` | A | `47.xxx.xxx.xxx` | www 子域 |
| `api` | A | `47.xxx.xxx.xxx` | API 子域（可选） |

## 四、阿里云 Mac 客户端（你问的就是这个）

阿里云有**三个**桌面端工具，分别管不同的事：

### 4.1 `阿里云` App（Mac App Store · 官方控制台 App）

**用途**：管账户 / 看资源 / 改配置 / 看监控 / 续费
**下载**：
- 直接打开 **Mac App Store** → 搜 "**阿里云**"（开发者：Alibaba Cloud / 阿里云计算有限公司）
- 或访问：https://apps.apple.com/cn/app/阿里云/id1518995087
- 或 PC 浏览器搜："阿里云 Mac 客户端"，官网下载页：
  https://help.aliyun.com/document_detail/138820.html

**重要**：识别正版的方法 —— 开发者必须是 "**Alibaba Cloud (Singapore) Private Limited**" 或 "**阿里云计算有限公司**"，其他都是仿冒。

### 4.2 `Workbench` 阿里云远程连接工具（独立 App）

**用途**：免密 SSH 登录 ECS（不用记 IP/密码，浏览器或客户端直连）
**下载**：阿里云控制台 → 任意 ECS 实例详情页 → "远程连接" → 推荐安装 **Workbench**
**官方下载**：https://help.aliyun.com/zh/ecs/user-guide/connect-to-a-linux-instance-by-using-workbench

### 4.3 `Cloud Shell`（浏览器内置，无需下载）

**用途**：临时执行 aliyun 命令、跑脚本
**入口**：阿里云控制台右上角终端图标

### 4.4 你的工具组合推荐

| 工具 | 必装 | 用途 |
|------|------|------|
| 阿里云 Mac App | ✅ | 日常看账单 / 续费 / 应急 |
| iTerm2（免费） | ✅ | SSH 终端，比 macOS 自带 Terminal 强 |
| Workbench | 可选 | 没装 SSH 公钥时备用 |
| Termius（免费 + 付费） | 可选 | 多服务器统一管理 |

## 六、避坑清单（PUA 红线）

| 坑 | 后果 | 避坑 |
|----|------|------|
| 买 ECS 不买轻量 | 多花 2~3 倍钱 | 起步坚定买**轻量应用服务器** |
| 选大陆节点但没备案 | 域名无法解析国内访问 | 起步先选**香港地域**，再迁 |
| 域名含商标词（douyin/tiktok） | 域名注册被驳回 + 备案失败 | 用你自己的品牌词 |
| 没建信息模板就买 | 流程卡半天 | **先建信息模板，再买域名** |
| 买高带宽 | 钱包流血 | 起步 **3M 够用**，CDN 兜底 |
| 买 Windows Server | 装东西麻烦 | 必选 **Ubuntu 22.04 LTS** |
| 装非官方 App | 账号被盗 | 只从 Mac App Store / 阿里云官网下 |
